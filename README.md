# Smart Parking Management System

## Project Overview

The **Smart Parking Management System** is a database-based web application developed to simplify and improve parking management. It provides a centralized platform to manage parking areas, parking slots, vehicle owners, vehicle details, parking entries and exits, and payment records.

The system helps reduce manual parking operations, maintain accurate parking records, prevent duplicate slot allocation, and improve parking space utilization.

## Objectives

- Manage multiple parking areas and their locations.
- Maintain parking slot availability and occupancy status.
- Store vehicle and vehicle owner information.
- Record vehicle entry and exit times.
- Calculate parking
